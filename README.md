# MALMOA plugins

Native plugin for Codex and Claude Code.

```sh
codex plugin marketplace add https://github.com/MyKnow/malmoa-plugins.git
codex plugin add malmoa@malmoa
claude plugin marketplace add https://github.com/MyKnow/malmoa-plugins.git
claude plugin install malmoa@malmoa --scope user
```

Open the MALMOA connect skill in your project to log in and select a project. Credentials stay in the OS credential store. Host trust approval and a new session may be required.
