# Durumari plugins

Native plugin for Codex and Claude Code. Run these commands from this extracted catalog.

```sh
codex plugin marketplace add .
codex plugin add durumari@durumari
claude plugin marketplace add .
claude plugin install durumari@durumari --scope user
```

Open the Durumari connect skill in your project to log in and select a project. Credentials stay in the OS credential store. Host trust approval and a new session may be required.
